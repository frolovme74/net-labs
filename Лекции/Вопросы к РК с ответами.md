### Упражнения в середине лекции (слайды 6–11): пересылка кадров по таблице MAC-адресов

Порты: 0A — Fa1, 0B — Fa3, 0C — Fa5, 0D — Fa7, 0E и 0F — Fa9 (через концентратор).

**Упражнение 1.** Кадр: назначение 0C, источник 0A, пришёл на Fa1. Таблица заполнена полностью.
- Вопрос 1. Куда коммутатор перешлёт кадр? → **Fa5** ✅
- Вопрос 2. Верное утверждение → **Кадр является одноадресным и будет пересылаться только на один определённый порт** ✅

*0A уже есть в таблице, поэтому ничего не добавляется; 0C известен — кадр уходит только на Fa5.*

**Упражнение 2.** Кадр: назначение 0B, источник 0D, пришёл на Fa7. В таблице нет записи для 0D.
- Вопрос 1. → **Fa3** ✅
- Вопрос 2. → **Коммутатор добавляет MAC-адрес источника в таблицу MAC-адресов** ✅ и **Кадр является одноадресным и будет пересылаться только на один определённый порт** ✅

**Упражнение 3.** Кадр: назначение 0B, источник 0C, пришёл на Fa5. В таблице есть только 0B (Fa3), 0D (Fa7), 0E/0F (Fa9).
- Вопрос 1. → **Fa3** ✅
- Вопрос 2. → **Коммутатор добавляет MAC-адрес источника в таблицу** ✅ и **Кадр одноадресный, пересылается только на один порт** ✅

*Правило из лекции: шаг 1 — изучение MAC-адреса источника (если его нет — добавить), шаг 2 — поиск MAC-адреса получателя (если найден — переслать только на этот порт; если не найден — лавинная рассылка на все порты, кроме входного).*

## Лекция 8. Статическая и динамическая маршрутизация: задания на настройку

Топология: R1 (172.16.3.0/24, 2001:db8:acad:3::/64) — 172.16.2.0/24 (2001:db8:acad:2::/64) — R2 (172.16.1.0/24, 2001:db8:acad:1::/64) — 192.168.1.0/24 (2001:db8:cafe:1::/64) — R3 (192.168.2.0/24, 2001:db8:cafe:2::/64).
Адреса: в сети 172.16.2.0/24 R1 = .1, R2 = .2; в сети 192.168.1.0/24 R2 = .2, R3 = .1 (для IPv6 так же: 2001:db8:cafe:1::2 — R2, ::1 — R3). В последних заданиях добавлен канал R1–R3: 10.10.10.0/24 (2001:db8:feed:10::/64), R1 = .1, R3 = .2.

Синтаксис из лекции:
- `ip route network-address subnet-mask {ip-address | exit-intf [ip-address]} [distance]`
- `ipv6 route ipv6-prefix/prefix-length {ipv6-address | exit-intf [ipv6-address]} [distance]`
- маршрут по умолчанию: `ip route 0.0.0.0 0.0.0.0 {ip-address | exit-intf}`, `ipv6 route ::/0 {ipv6-address | exit-intf}`

**1. Настройте статический маршрут к сети 192.168.2.0/24, используя адрес следующего перехода 192.168.1.1.** (на R2)
```
R2(config)# ip route 192.168.2.0 255.255.255.0 192.168.1.1
```

**2. Настройте полностью определенный статический маршрут на R2 к сети 172.16.3.0/24 с использованием пары выходной интерфейс/следующий переход: G0/1 / 172.16.2.1.**
```
R2(config)# ip route 172.16.3.0 255.255.255.0 g0/0/1 172.16.2.1
```

**3. Настройте статический маршрут следующего перехода IPv6 на R2 в сеть 2001:db8:cafe:2::/64, используя адрес следующего перехода 2001:db8:cafe:1::1.**
```
R2(config)# ipv6 route 2001:db8:cafe:2::/64 2001:db8:cafe:1::1
```

**4. Настройте статический маршрут IPv4 по умолчанию на R3 для доступа ко всем удаленным сетям. Используйте IP-адрес следующего перехода в качестве аргумента.**
